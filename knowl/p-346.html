Terms in an algebraic expression that can be combined by adding them together into one new term are called like terms.
  • Sometimes like terms use a common variable, like how \(2x+3x\) has terms that each use \(x\text{.}\) This simplfies to \(5x\text{.}\)
  • Sometimes like terms use the same units, like how \(3\,\text{cm}+2\,\text{cm}\) has terms that each use cm. This simplfies to 5 cm.
  • Sometimes like terms have something else in common, like how \(3\sqrt{7}+2\sqrt{7}\) has terms that each use \(\sqrt{7}\text{.}\) This simplfies to \(5\sqrt{7}\text{.}\)
