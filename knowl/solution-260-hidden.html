We substitute in each ordered pair’s \(x\)- and \(y\)-values into the equation \(y=-10 x - 5\text{,}\) and see whether the resulting equation is true.
In one case, \((-2,16)\text{,}\) we have
\(\begin{aligned} 16 \amp \stackrel{?}{=} -10(-2) - 5\\ 16 \amp \stackrel{?}{=} 20 - 5\\ 16 \amp \stackrel{?}{=} 15\\ \end{aligned}\)
which is a false equation. So \((-2,16)\) is not a solution to the given equation.
In each other case, for example with \((3,-35)\text{,}\) we have a true equation:
\(\begin{aligned} -35 \amp \stackrel{?}{=} -10(3) - 5\\ -35 \amp \stackrel{?}{=} -30 - 5\\ -35 \amp \stackrel{?}{=} -35\\ \end{aligned}\)
So the other three points are solutions.
