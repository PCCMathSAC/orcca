The solution to this equation is \(10\text{.}\) To stress that this is a value assigned to \(a\text{,}\) some report \(a = 10\text{.}\) We can also say that the solution set is \(\{10\}\text{,}\) or that \(a\in\left\{10\right\}\text{.}\) If we substitute \(10\) in for \(a\) in the original equation \(-2a+4=-a-6\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
