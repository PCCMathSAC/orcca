Explanation 2.5.3.8.1.
Two approaches are shown below.
\(\displaystyle{\begin{aligned} 24 \amp = -2(C -8) \amp 24 \amp = -2(C -8)\\ 24 \amp = -2(C +(-8)) \amp \frac{24}{-2} \amp = \frac{-2(C -8)}{-2}\\ 24 \amp = -2C +(-2) \cdot (-8) \amp -12 \amp = C -8\\ 24 \amp = -2C +16 \amp -12\mathbf{{}+8} \amp = C -8\mathbf{{}+8}\\ 24 \mathbf{{}-16} \amp = -2C +16\mathbf{{}-16} \amp -4 \amp = C\\ 8 \amp = -2C \amp C \amp = -4\\ \frac{8}{-2} \amp = \frac{-2C}{-2} \\ -4 \amp = C\\ C \amp = -4 \end{aligned} }\)
The solution to this equation is \(-4\text{.}\) To stress that this is a value assigned to \(C\text{,}\) some report \(C = -4\text{.}\) We can also say that the solution set is \(\{-4\}\text{,}\) or that \(C\in\left\{-4\right\}\text{.}\) If we substitute \(-4\) in for \(C\) in the original equation \(24=-2\mathopen{}\left(C-8\right)\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
