The solution to this equation is \(1\text{.}\) To stress that this is a value assigned to \(A\text{,}\) some report \(A = 1\text{.}\) We can also say that the solution set is \(\{1\}\text{,}\) or that \(A\in\left\{1\right\}\text{.}\) If we substitute \(1\) in for \(A\) in the original equation \(-10A-1=-11\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
