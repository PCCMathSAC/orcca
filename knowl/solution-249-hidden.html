It’s easier to do this problem if we substitute \((x,y)\) with some random numbers.
If the point \((x,y)\) if in Quadrant II, say it’s \((-1,1)\text{,}\) then:
the point \((-x,y)\text{,}\) or \((1,1)\text{,}\) is in Quadrant I.
the point \((x,-y)\text{,}\) or \((-1,-1)\text{,}\) is in Quadrant III.
the point \((-x,-y)\text{,}\) or \((1,-1)\text{,}\) is in Quadrant IV.
