Item 3.6.5.66.a.
A line’s equation in point-slope form looks like \(y=m(x-x_0)+y_0\text{,}\) where \(m\) is the slope, and \((x_0,y_0)\) is some point we know to be on the line. We first need to find the line’s slope. To find the slope, we need two points on the line. We have been given that \((11,14.23)\) and \((17,15.61)\) are points on the linear model, so we can use the slope formula:
\(\displaystyle{ \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} }\)
First, we mark which number corresponds to which variable in the formula:
\(\displaystyle{ (11,14.23) \longrightarrow (x_{1},y_{1}) }\)
\(\displaystyle{ (17,15.61) \longrightarrow (x_{2},y_{2}) }\)
Now we substitute these numbers into the corresponding variables in the slope formula:
\(\displaystyle{ \begin{aligned}\text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\\amp =\frac{15.61-14.23}{17-11}\\\amp =\frac{1.38}{6}\\\amp =0.23 \end{aligned}}\)
This line’s slope is \(0.23\text{.}\) This implies that the tree is growing by \(0.23\) feet each month.
So now we have that \(y=0.23(x-x_0)+y_0\text{.}\) We can either use \((x_0,y_0)=(11,14.23)\) or \((x_0,y_0)=(17,15.61)\) to get \({y = 0.23\mathopen{}\left(x-11\right)+14.23\hbox{ or }y = 0.23\mathopen{}\left(x-17\right)+15.61}\text{.}\)
