When we add a negative number with a positive number, we need to find the difference of their absolute values. When doing decimal subtractions, make sure to line up the decimal points. For the integer \(-28\text{,}\) the decimal point is at the end of the number, like in \(-28.00\)
\(\displaystyle{\begin{aligned}[t] \amp \phantom{-}28.00 \\ \amp \underline{-\phantom{2}8.81\phantom{ad}} \\ \amp \phantom{-}19.19 \end{aligned} }\)
Next, since the absolute value of \(-28\) is bigger than that of \(8.81\text{,}\) the result is negative.
\(-28 + 8.81 = -19.19\)
