Explanation 2.4.4.14.1.
\(\displaystyle{\begin{aligned} 7C-8-8C \amp = -10-C+2 \\ (7-8)C-8 \amp = (-10+2)-C \\ -C -8 \amp = -8-C \\ -C -8 \mathbf{{}+C +8} \amp = -8-C\mathbf{{}+C +8} \\ 0 \amp = 0 \end{aligned} }\)
Since the original equation is equivalent to an equation that is true no matter what the value of \(C\) is, the equation’s solution set is all real numbers.
