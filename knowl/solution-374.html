Explanation 3.4.5.51.1.
To find the slope, we need two points on the line. We have been given that \((7,342)\) and \((19,228)\) are points on the linear model, so we can use the slope formula:
\(\displaystyle{ \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} }\)
First, we mark which number corresponds to which variable in the formula:
\(\displaystyle{ (7,342) \longrightarrow (x_{1},y_{1}) }\)
\(\displaystyle{ (19,228) \longrightarrow (x_{2},y_{2}) }\)
Now we substitute these numbers into the corresponding variables in the slope formula:
\(\displaystyle{ \begin{aligned}\text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\\amp =\frac{228-342}{19-7}\\\amp =\frac{-114}{12}\\\amp =-9.5 \end{aligned}}\)
This line’s slope is \(-9.5\text{.}\) This implies that the gas is leaking with a rate of \({9.5\ {\textstyle\frac{\rm\mathstrut g}{\rm\mathstrut min}}}\text{.}\)
