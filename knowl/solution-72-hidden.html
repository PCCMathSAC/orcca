To solve this inequality, we need to multiply by \(-2\) to each side. Since \(-2\) is negative, we will need to change the direction of the inequality.
\begin{equation*} \begin{aligned} -\frac{1}{2}z\amp\lt2\\ \multiplyleft{-2}\left(-\frac{1}{2}z\right)\amp\highlight{\gt}\multiplyleft{-2}(2)\\ z\amp\gt-4 \end{aligned} \end{equation*}
