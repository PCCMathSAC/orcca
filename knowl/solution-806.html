Explanation A.1.7.41.1.

When we add a negative number with a positive number, we need to find the difference of their absolute values. To subtract two decimals, make sure to line up the decimal points:
\(\displaystyle{\begin{aligned}[t] \amp \phantom{-}7.90 \\ \amp \underline{-2.42\phantom{ad}} \\ \amp \phantom{-}5.48 \end{aligned} }\)
Note that we added an extra \(0\) to the end of \(7.9\) before doing subtraction.
Finally, since the absolute value of \(- 2.42\) is smaller than the absolute value of \(7.9\text{,}\) the result is positive.
\(- 2.42 + 7.9 = 5.48\)
