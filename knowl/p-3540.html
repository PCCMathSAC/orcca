The solution to this equation is \(3\text{.}\) To stress that this is a value assigned to \(q\text{,}\) some report \(q = 3\text{.}\) We can also say that the solution set is \(\{3\}\text{,}\) or that \(q\in\left\{3\right\}\text{.}\) If we substitute \(3\) in for \(q\) in the original equation \(3q+6=15\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
