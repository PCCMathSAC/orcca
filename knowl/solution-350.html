Explanation 3.4.5.23.1.
To find a line’s slope, we can use the slope formula:
\begin{equation*} \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} \end{equation*}
First, we mark which number corresponds to which variable in the formula:
\begin{equation*} (-6,{11}) \longrightarrow (x_{1},y_{1}) \end{equation*}
\begin{equation*} (18,{-9}) \longrightarrow (x_{2},y_{2}) \end{equation*}
Now we substitute these numbers into the corresponding variables in the slope formula:
\begin{equation*} \begin{aligned} \text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{{-9}-{11}}{18-(-6)}\\ \amp =\frac{{-20}}{24}\\ \amp =-\frac{5}{6} \end{aligned} \end{equation*}
So the line’s slope is \(\displaystyle{-\frac{5}{6}}\text{.}\)
