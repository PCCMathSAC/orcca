Explanation 2.4.4.11.1.
\(\displaystyle{\begin{aligned} 8a+5 \amp = 8a+5 \\ 8a+5\mathbf{{}-8a -5} \amp = 8a+5\mathbf{{}-8a -5} \\ 0\amp = 0 \end{aligned} }\)
Since the original equation is equivalent to an equation that is true no matter what the value of \(a\) is, the equation’s solution set is all real numbers.
