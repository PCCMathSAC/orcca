To find a line’s slope, we can use the slope formula:
\(\displaystyle{ \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} }\)
For line \(m\text{,}\) we have:
\(\displaystyle{ \begin{aligned}\text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{9-10}{-3-(-3)}\\ \amp =\frac{-1}{0}\\ \amp =\text{undefined} \end{aligned}}\)
This is a special line, \(x=-3\text{.}\) It is vertical with an undefined slope.
For line \(n\text{,}\) we have:
\(\displaystyle{\begin{aligned} \text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{-9-(-6)}{8-8}\\ \amp =\frac{-3}{0}\\ \amp =\text{undefined} \end{aligned}}\)
This is a special line, \(x=8\text{.}\) It is vertical with an undefined slope.
Since both lines are vertical, these two lines are parallel.
