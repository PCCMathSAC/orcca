Explanation 3.3.5.24.1.
The \(x\)-values in this table jump erratically. However, if we compute the rate of change between consecutive rows in the table, the result is always 2. For example, the rate of change between the first and second rows is
\begin{equation*} \frac{{85}-{83}}{4-3}=\frac{{2}}{1}=2 \text{.} \end{equation*}
