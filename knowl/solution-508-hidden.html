1. A line’s equation in point-slope form looks like \(y=m(x-x_0)+y_0\text{,}\) where \(m\) is the slope, and \((x_0,y_0)\) is some point we know to be on the line. We first need to find the line’s slope. To find the slope, we need two points on the line. We have been given that \((9,180)\) and \((15,150)\) are points on the linear model, so we can use the slope formula:
    \(\displaystyle{ \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} }\)
    First, we mark which number corresponds to which variable in the formula:
    \(\displaystyle{ (9,180) \longrightarrow (x_{1},y_{1}) }\)
    \(\displaystyle{ (15,150) \longrightarrow (x_{2},y_{2}) }\)
    Now we substitute these numbers into the corresponding variables in the slope formula:
    \(\displaystyle{ \begin{aligned}\text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\\amp =\frac{150-180}{15-9}\\\amp =\frac{-30}{6}\\\amp =-5 \end{aligned}}\)
    This line’s slope is \(-5\text{.}\) This implies that the gas is leaking with a rate of \(5\) grams per minute.
    So now we have that \(y=-5(x-x_0)+y_0\text{.}\) We can either use \((x_0,y_0)=(9,180)\) or \((x_0,y_0)=(15,150)\) to get \({y = -5\mathopen{}\left(x-9\right)+180\hbox{ or }y = -5\mathopen{}\left(x-15\right)+150}\text{.}\)
  2. After \(39\) minutes, we can find the mass of the remaining gas if we substitute \(39\) in for \(x\) in the equation \(y=-5(x-9)+180\text{,}\) and we have:
    \(\displaystyle{\begin{aligned} y \amp = -5(39-9) +180 \\ y \amp = 30 \end{aligned} }\)
    So after \(39\) minutes, there are \(30\) grams of gas remaining.
  3. To find when the gas will be all gone, we need to find when there are \(0\) grams of gas left. We can substitute \(0\) in for \(y\) in the equation \(y=-5(x-9)+180\text{,}\) and we have:
    \(\displaystyle{\begin{aligned} y \amp = -5(x-9) +180 \\ 0 \amp = -5(x-9) +180 \\ -180 \amp = -5(x-9)\\ \frac{-180}{-5} \amp = x - 9\\ 36 \amp = x - 9\\ 45 \amp = x\\ 45 \amp = x \end{aligned} }\)
    So after \(45\) minutes, the gas will be all gone.
