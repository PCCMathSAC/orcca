Explanation 1.5.20.1.

Since \(\frac23\) is added to \(g\text{,}\) we will ssubtract \(\frac23\) from each side.
\begin{align*} \frac{2}{3}+g\amp=\frac{1}{2}\\ \frac{2}{3}+g\subtractright{\frac{2}{3}}\amp=\frac{1}{2}\subtractright{\frac{2}{3}}\\ g\amp=\highlight{\frac{3}{6}}-\highlight{\frac{4}{6}}\\ g\amp=-\frac{1}{6} \end{align*}
We should check the solution by substituting \(-\frac{1}{6}\) in for \(g\text{:}\)
\begin{align*} \frac{2}{3}+g\amp=\frac{1}{2}\\ \frac{2}{3}+\left(\substitute{-\frac{1}{6}}\right)\amp\wonder{=}\frac{1}{2}\\ \frac{4}{6}+\left(-\frac{1}{6}\right)\amp\wonder{=}\frac{1}{2}\\ \frac{3}{6}\amp\confirm{=}\frac{1}{2} \end{align*}
The solution \(-\frac{1}{6}\) is checked, and the solution set is \(\left\{-\frac{1}{6}\right\}\text{.}\)
