To remove the \(\frac{3}{7}\) from the left side, we need to add \(\frac{3}{7}\) to each side of the equation.
\begin{equation*} \begin{aligned} q-\frac{3}{7}\amp=\frac{3}{2}\\ q-\frac{3}{7}\addright{\frac{3}{7}}\amp=\frac{3}{2}\addright{\frac{3}{7}}\\ q\amp=\highlight{\frac{21}{14}}+\highlight{\frac{6}{14}}\\ q\amp=\frac{27}{14} \end{aligned} \end{equation*}
We should check the solution by substituting \(\frac{27}{14}\) in for \(q\) in the original equation:
\begin{equation*} \begin{aligned} q-\frac{3}{7}\amp=\frac{3}{2}\\ \substitute{\frac{27}{14}}-\frac{3}{7}\amp\wonder{=}\frac{3}{2}\\ \frac{27}{14}-\frac{6}{14}\amp\wonder{=}\frac{3}{2}\\ \frac{21}{14}\amp\wonder{=}\frac{3}{2}\\ \frac{3}{2}\amp\confirm{=}\frac{3}{2} \end{aligned} \end{equation*}
The solution \(\frac{27}{14}\) is checked, and the solution set is \(\left\{\frac{27}{14}\right\}\text{.}\)
