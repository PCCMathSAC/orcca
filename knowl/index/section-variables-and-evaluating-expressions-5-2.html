Any combination of variables and numbers using arithmetic operations (like addition, multiplication, etc.) is an algebraic expression. The following are examples of algebraic expressions:
\begin{equation*} x+1\qquad 2\ell+2w\qquad\frac{\sqrt{x}}{y+1}\qquad nRT \end{equation*}
Note that this definition of “algebraic expression” does not include anything with an equal sign (\(=\)) in it. The idea of an equation (which has an equals sign) is discussed in Section 4.
