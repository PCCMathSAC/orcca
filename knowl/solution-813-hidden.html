When we add a negative number with a positive number, we need to find the difference of their absolute values. When doing decimal subtractions, make sure to line up the decimal points. For the integer \(-35\text{,}\) the decimal point is at the end of the number, like in \(-35.00\)
\(\displaystyle{\begin{aligned}[t] \amp \phantom{-}35.00 \\ \amp \underline{-\phantom{3}2.51\phantom{ad}} \\ \amp \phantom{-}32.49 \end{aligned} }\)
Next, since the absolute value of \(-35\) is bigger than that of \(2.51\text{,}\) the result is negative.
\(-35 + 2.51 = -32.49\)
