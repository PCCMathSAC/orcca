Warning 2.4.5.

Note that there is a very important difference between when our process ends with \(0=0\) and when it ends with \(x=0\text{.}\) The first equation is true for all values that \(x\) might have, and the solution set is \((-\infty,\infty)\text{.}\) The second situation has only one solution, \(0\text{,}\) and the solution set is \(\{0\}\text{.}\)
