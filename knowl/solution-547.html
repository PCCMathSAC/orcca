Explanation 3.7.5.48.1.
Assume \(x\) years since its purchase, the car’s value is \(y\) dollars. A linear equation to model the car’s value is:
\(\displaystyle{ y = -2200x+39600 }\)
Since this line is in its slope-intercept mode, we can see its \(y\)-intercept is \((0,39600)\text{.}\)
The correct solution is: The y-intercept is (0,39600). It implies the car’s initial value was 39600.
