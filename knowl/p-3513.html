Now we have an equation where \(w\) is islated. For example if we want to find the width when \(A=12\) and \(\ell=4\text{,}\) we have a formula: \(w=\frac{A}{\ell}=\frac{12}{4}=3\text{.}\) This formula can be used again: what if \(A=100\) and \(\ell=20\text{?}\) Or if \(A=23.47\) and \(\ell=2.71\text{?}\) This formula, \(w=\frac{A}{\ell}\text{,}\) is a handy alternate to the original formula \(A=\ell w\) for situations where \(w\) is the unknown value.
