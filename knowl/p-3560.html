The solution to this equation is \(9\text{.}\) To stress that this is a value assigned to \(b\text{,}\) some report \(b = 9\text{.}\) We can also say that the solution set is \(\{9\}\text{,}\) or that \(b\in\left\{9\right\}\text{.}\) If we substitute \(9\) in for \(b\) in the original equation \(-9b+10=-b-62\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
