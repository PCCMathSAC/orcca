Explanation 2.4.4.7.1.
Two approaches are shown below.
\(\displaystyle{\begin{aligned} 28 \amp = -2(p -8) \amp 28 \amp = -2(p -8)\\ 28 \amp = -2(p +(-8)) \amp \frac{28}{-2} \amp = \frac{-2(p -8)}{-2}\\ 28 \amp = -2p +(-2) \cdot (-8) \amp -14 \amp = p -8\\ 28 \amp = -2p +16 \amp -14\mathbf{{}+8} \amp = p -8\mathbf{{}+8}\\ 28 \mathbf{{}-16} \amp = -2p +16\mathbf{{}-16} \amp -6 \amp = p\\ 12 \amp = -2p \amp p \amp = -6\\ \frac{12}{-2} \amp = \frac{-2p}{-2} \\ -6 \amp = p\\ p \amp = -6 \end{aligned} }\)
The solution to this equation is \(-6\text{.}\) To stress that this is a value assigned to \(p\text{,}\) some report \(p = -6\text{.}\) We can also say that the solution set is \(\{-6\}\text{,}\) or that \(p\in\left\{-6\right\}\text{.}\) If we substitute \(-6\) in for \(p\) in the original equation \(28=-2\mathopen{}\left(p-8\right)\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
