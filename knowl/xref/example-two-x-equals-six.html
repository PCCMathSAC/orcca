Example 1.5.6.

If a number mmultiplied by \(2\) is \(6\text{,}\) what is that number? The mystery number is small, since it gets multipled by \(2\) to make \(6\text{.}\) If we divide \(6\) by \(2\text{,}\) we will find the unknown number. Note that division is the opposite action of multiplication.
So the unknown number is \(\frac{6}{2}=3\text{.}\)
