  1. The absolute value of \(4\) measures how many units are between \(4\) and \(0\) on the number line, so \(|{4}|=4\text{.}\)
  2. The absolute value of \(-4\) measures how many units are between \(-4\) and \(0\) on the number line, so \(|{-4}|=4\text{.}\)
  3. The absolute value symbols cannot affect what are outside them, so we have \(-|{4}|=-4\text{.}\)
  4. Similar to Part c, we have \(-|{-4}|=-4\text{.}\)
