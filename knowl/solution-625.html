Explanation 3.10.9.14.1.
To find a line’s slope, we can use the slope formula:
\begin{equation*} \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} \end{equation*}
First, we mark which number corresponds to which variable in the formula:
\begin{equation*} (-8,{23}) \longrightarrow (x_{1},y_{1}) \end{equation*}
\begin{equation*} (8,{-5}) \longrightarrow (x_{2},y_{2}) \end{equation*}
Now we substitute these numbers into the corresponding variables in the slope formula:
\begin{equation*} \begin{aligned} \text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{{-5}-{23}}{8-(-8)}\\ \amp =\frac{{-28}}{16}\\ \amp =-\frac{7}{4} \end{aligned} \end{equation*}
So the line’s slope is \(\displaystyle{-\frac{7}{4}}\text{.}\)
