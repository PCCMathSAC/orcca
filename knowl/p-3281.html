The solution to this equation is \(4\text{.}\) To stress that this is a value assigned to \(t\text{,}\) some report \(t = 4\text{.}\) We can also say that the solution set is \(\{4\}\text{,}\) or that \(t\in\left\{4\right\}\text{.}\) If we substitute \(4\) in for \(t\) in the original equation \(3t+6=18\text{,}\) the equation will be true. Please check this on your own; it is an important habit.
