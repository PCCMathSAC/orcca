Explanation 2.3.13.1.

The LCM of the denominators is \(21\text{,}\) so we start out by multiplying each side of the inequality by \(21\text{.}\)
\begin{equation*} \begin{aligned} \frac{4}{7}-\frac{4}{3}x\amp\le\frac{2}{3}\\ \multiplyleft{21}\left(\frac{4}{7}-\frac{4}{3}x\right)\amp\le\multiplyleft{21}\left(\frac{2}{3}\right)\\ 21\left(\frac{4}{7}\right)-21\left(\frac{4}{3}x\right)\amp\le21\left(\frac{2}{3}\right)\\ 12-28x\amp\le14\\ -28x\amp\le2\\ \divideunder{-28x}{-28}\amp\highlight{{}\ge{}}\divideunder{2}{-28}\\ x\amp\ge-\frac{1}{14} \end{aligned} \end{equation*}
Note that when we divided each side of the inequality by \(-28\text{,}\) the inequality symbol reversed direction. The solution set in set-builder notation is \(\left\{x\mid x\ge-\frac{1}{14}\right\}\text{.}\) The solution set in interval notation is \(\left[-\frac{1}{14},\infty\right)\text{.}\)
