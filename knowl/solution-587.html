Explanation 3.8.5.37.1.
To find a line’s slope, we can use the slope formula:
\(\displaystyle{ \text{slope}=\frac{y_{2}-y_{1}}{x_{2}-x_{1}} }\)
For line \(m\text{,}\) we have:
\(\displaystyle{ \begin{aligned}\text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{3-5}{5-5}\\ \amp =\frac{-2}{0}\\ \amp =\text{undefined} \end{aligned}}\)
This is a special line, \(x=5\text{.}\) It is vertical with an undefined slope.
For line \(n\text{,}\) we have:
\(\displaystyle{\begin{aligned} \text{slope}\amp =\frac{y_{2}-y_{1}}{x_{2}-x_{1}}\\ \amp =\frac{4-8}{-10-(-10)}\\ \amp =\frac{-4}{0}\\ \amp =\text{undefined} \end{aligned}}\)
This is a special line, \(x=-10\text{.}\) It is vertical with an undefined slope.
Since both lines are vertical, these two lines are parallel.
