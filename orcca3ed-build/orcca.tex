\begin{paragraphs}{HTML, PDF, and print.}{preface-to-all-2}%
This book is freely available in the following formats: HTML, ePub, PDF-for-screen, PDF-for-print, and Braille. Additionally, a printed and bound copy is available for purchase at low cost. Information about all versions can be found at \href{https://www.pcc.edu/orcca}{\nolinkurl{pcc.edu/orcca}}.%
\par
There are some notable differences between the HTML version, PDF-for-screen, and PDF-for-print.%
\begin{itemize}[label=\textbullet]
\item{}The HTML version offers interactive elements, easier navigation than print, and its content is web accessible.%
\item{}Two PDF versions can be downloaded.  One version is intended to be read on a screen with a PDF viewer. This version retains full color, has its text centered on the page, and includes hyperlinking. The other version is intended for printing on two-sided paper and then binding. Most of its color has been converted with care to grayscale. Text is positioned to the left or right of each page in a manner to support two-sided binding. Hyperlinks have been disabled.%
\item{}Printed and bound copies are available for purchase online. Up-to-date information about purchasing a copy should be available at \href{https://www.pcc.edu/orcca}{\nolinkurl{pcc.edu/orcca}}. Contact \href{mailto:orcca-group@pcc.edu}{\nolinkurl{orcca-group@pcc.edu}} if you have trouble finding the latest version online.%
\end{itemize}
%
\end{paragraphs}%
\begin{paragraphs}{Copying Content.}{preface-to-all-3}%
The source files for this book are available through \href{https://www.pcc.edu/orcca}{\nolinkurl{pcc.edu/orcca'}}, and openly licensed for use. However, it may be more convenient to copy certain things directly from the HTML version.%
\par
The graphs and other images that appear in this book are available in various file formats. While viewing the book with a web browser, right-click on an image to view it in a new tab. The web browser will reveal the path to the image. In almost all cases, you will initially see an \mono{.svg} version of the image. But editing that extension to \mono{.png}, \mono{.eps}, \mono{.pdf}, and \mono{.tex} will provide access to these other formats.%
\par
Mathematical content can be copied from the HTML version. To copy math content into \pubtitle{MS Word}, right-click or control-click over the math content, and click to \mono{Show Math As MathML Code}. Click ``Copy to Clipboard''. In \pubtitle{Word}, use \mono{Paste Special} to paste the content as \mono{Unformatted Text}. To copy math content into \LaTeX{} source, right-click or control-click over the math content, and click to \mono{Show Math As TeX Commands}.%
\par
Tables can be copied from the HTML version and pasted into applications like \pubtitle{MS Word}. However, mathematical content within tables will not always paste correctly without a little extra effort as described above.%
\end{paragraphs}%
\begin{paragraphs}{Accessibility.}{preface-to-all-4}%
The eBook version is intended to meet or exceed web accessibility standards. If you encounter an accessibility issue, please report it.%
\begin{itemize}[label=\textbullet]
\item{}All graphs and images should have meaningful alt text that communicates what a sighted person would see, without necessarily giving away anything that is intended to be deduced from the image.%
\item{}All math content is rendered using MathJax. MathJax has a contextual menu that can be accessed in several ways, depending on what operating system and browser you are using. The most common way is to right-click or control-click on some piece of math content.%
\item{}In the MathJax contextual menu, you may set options for triggering a zoom effect on math content, and also by what factor the zoom will be. Also in the MathJax contextual menu, you can activate more accessibility tools, including the ability to display speech strings for math expressions. Setting the speech strings to the ``Clearspeak'' rules produces speech strings that are intended to match how the math would be spoken aloud.%

\typeout{Subsection 1.1.1 Solving Quadratic Equations Using the Square Root Property}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{Solving Quadratic Equations Using the Square Root Property}{}{Solving Quadratic Equations Using the Square Root Property}{}{}{section-solving-quadratic-equations-by-using-a-square-root-4}
\index{solving!quadratic equations!using the square root property}%
When we learned how to solve linear equations, we used inverse operations to isolate the variable. For example, we use \emph{subtraction} to remove an unwanted term that is \emph{added} to one side of a linear equation. When a variable appears in an equation and it is \emph{squared}, we might be able to do something similar and use a \emph{square root} to help find the solution(s). Taking the square root is the inverse of squaring if you happen to know the original number was positive. Even if you don't know that, we can still come to a conclusion about solutions to certain types of equation where the variable is squared.%
\par
For example, if \(x^2=9\), we can think of undoing the square with a square root, and we know \(\sqrt{9}=3\). However, there are actually \emph{two} numbers that we can square to get \(9\): \(-3\) as well as \(3\). Both are solutions, and both are in the solution set. This demonstrates something called the Square Root Property.%
\begin{fact}{Fact}{Square Root Property.}{}{fact-square-root-property}%
\index{square root property}%
\index{properties!square root property}%
If \(k\) is positive and \(x^2=k\), then%
\begin{equation*}
x=-\sqrt{k}\qquad\text{ or }\qquad x=\sqrt{k}\text{.}
\end{equation*}
%
\par
It is common to write \(x=\pm\sqrt{k}\) for short, but it is important to remember that this means \(x\) could possibly be one of two things: \(\sqrt{k}\) or \(-sqrt{k}\). It does not mean that \(x\) is two things at the same time. The positive solution, \(\sqrt{k}\), is called the \terminology{principal square root} of \(k\).%
\end{fact}
\begin{example}{Example}{}{example-solve-using-square-root-property}%
Solve for \(y\) in \(y^2=49\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{example-solve-using-square-root-property-2}{}\quad{}%
\begin{align*}
y^2\amp=49\\
y\amp=\pm\sqrt{49}\\
y\amp=\pm7
\end{align*}
%
\begin{align*}
y\amp=-7\amp\text{ or }\amp\amp y\amp=7
\end{align*}
%
}\par
To check these solutions, we substitute \(-7\) and \(7\) in for \(y\) in the original equation:%
\begin{align*}
y^2\amp=49\amp y^2\amp=49\\
(\substitute{-7})^2\amp\wonder{=}49\amp (\substitute{7})^2\amp\wonder{=}49\\
49\amp\confirm{=}49\amp 49\amp\confirm{=}49
\end{align*}
Both potential solutions work, and we conclude that the solution set is \(\{-7,7\}\).%
\end{example}
\begin{remark}{Remark}{}{section-solving-quadratic-equations-by-using-a-square-root-4-7}%
Every solution to a quadratic equation can be checked, as was done in \hyperref[example-solve-using-square-root-property]{Example~3}. In the examples that follow, we won't check solutions. But you should check solutions when solving exercises for your homework or exams.%
\end{remark}
\begin{inlineexercise}{Checkpoint}{}{section-solving-quadratic-equations-by-using-a-square-root-4-8}%
Solve for \(z\) in \(4z^2-81=0\text{.}\)%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-solving-quadratic-equations-by-using-a-square-root-4-8-3}{}\quad{}Before we can use the square root property we need to isolate the squared quantity.%
}\par
%
\begin{equation*}
\begin{aligned}
4z^2-81\amp=0\\
4z^2\amp=81\\
z^2\amp=\frac{81}{4}
\end{aligned}
\end{equation*}
Now we can use the square root property%
\begin{equation*}
\begin{aligned}
z\amp=\pm\sqrt{\frac{81}{4}}\\
z\amp=\pm\frac{9}{2}
\end{aligned}
\end{equation*}
%
\par
%
\begin{equation*}
\begin{aligned}
z\amp=-\frac{9}{2}\amp\text{ or }\amp\amp z\amp=\frac{9}{2}
\end{aligned}
\end{equation*}
%
\par
The solution set is \(\left\{-\frac{9}{2},\frac{9}{2}\right\}\text{.}\)%
\end{inlineexercise}%
We can also use the square root property to solve an equation that has a squared \emph{expression} (as opposed to an equation that only has a squared variable).%
\begin{example}{Example}{}{section-solving-quadratic-equations-by-using-a-square-root-4-10}%
Solve for \(p\) in \(50=2(p-1)^2\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-solving-quadratic-equations-by-using-a-square-root-4-10-2}{}\quad{}It's important here to suppress any urge you may have to expand the squared binomial. Perhaps you recently learned how to do that and practiced that skill. Good! But it would not be helpful to do that here. We will begin by isolating the squared expression.%
\begin{align*}
50\amp=2(p-1)^2\\
\divideunder{50}{2}\amp=\divideunder{2(p-1)^2}{2}\\
25\amp=(p-1)^2
\end{align*}
%
}\par
Now that we have the squared expression isolated, we can use the square root property.%
\begin{align*}
p-1\amp=\pm\sqrt{25}\\
p-1\amp=\pm5\\
p\amp=\pm5+1
\end{align*}
%
\begin{align*}
p\amp=-5+1\amp\text{or}\amp\amp p\amp=5+1\\
p\amp=-4\amp\text{or}\amp\amp p\amp=6
\end{align*}
The solution set is \(\{-4,6\}\).%
\end{example}
This method of solving quadratic equations is not limited to equations that have rational solutions, or solutions where the radicands are perfect squares. Here are a few examples where the solutions are irrational numbers.%
\begin{inlineexercise}{Checkpoint}{}{section-solving-quadratic-equations-by-using-a-square-root-4-12}%
Solve for \(q\) in \((q+2)^2-12=0\text{.}\)%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-solving-quadratic-equations-by-using-a-square-root-4-12-3}{}\quad{}It's important to suppress any urge to expand the squared binomial.%
}\par
%
\begin{equation*}
\begin{aligned}
(q+2)^2-12\amp=0\\
(q+2)^2\amp=12\\
q+2\amp=\pm\sqrt{12}\\
q+2\amp=\pm\sqrt{4\cdot3}\\
q+2\amp=\pm2\sqrt{3}\\
q\amp=\pm2\sqrt{3}-2
\end{aligned}
\end{equation*}
%
\par
%
\begin{equation*}
\begin{aligned}
q\amp=-2\sqrt{3}-2\amp\text{or}\amp\amp q\amp=2\sqrt{3}-2
\end{aligned}
\end{equation*}
%
\par
The solution set is \(\left\{-2\sqrt{3}-2,2\sqrt{3}-2\right\}\text{.}\)%
\end{inlineexercise}%
If we solve an equation like the ones we have been solving and end up with a radical in the denominator, we may be expected to rationalize it as covered in \mono{[cross-reference to target(s) \textquotedbl{}section-rationalizing-the-denominator\textquotedbl{} missing or not unique]}. We will rationalize a denominator in the next example.%
\begin{example}{Example}{}{example-solve-using-square-root-property-irrational-cannot-factor}%
Solve for \(n\) in \(2n^2-3=0\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{example-solve-using-square-root-property-irrational-cannot-factor-2}{}\quad{}%
\begin{align*}
2n^2-3\amp=0\\
2n^2\amp=3\\
n^2\amp=\frac{3}{2}\\
n\amp=\pm\sqrt{\frac{3}{2}}\\
n\amp=\pm\sqrt{\frac{6}{4}}\\
n\amp=\pm\frac{\sqrt{6}}{2}
\end{align*}
%
\begin{align*}
n\amp=-\frac{\sqrt{6}}{2}\amp\text{ or }\amp\amp n\amp=\frac{\sqrt{6}}{2}
\end{align*}
The solution set is \(\left\{-\frac{\sqrt{6}}{2},\frac{\sqrt{6}}{2}\right\}\).%
}\end{example}
Recall that we have no meaning for the square root of a negative number. (Later we will give meaning to that idea, but for now it is meaningless). So if the solving process we are using leads to the square root of a negative number, the original equation has no real solution. Here is an example of an equation with no real solution.%
\begin{example}{Example}{}{example-no-real-solution}%
Solve for \(x\) in \(x^2+49=0\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{example-no-real-solution-2}{}\quad{}%
\begin{align*}
x^2+49\amp=0\\
x^2\amp=-49
\end{align*}
Since \(\sqrt{-49}\) is not a real number, we say the equation has no real solution.%
}\end{example}
\end{subsectionptx}

\typeout{Subsection 1.1.2 The Pythagorean Theorem}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{The Pythagorean Theorem}{}{The Pythagorean Theorem}{}{}{subsection-pythagorean-theorem}
Right triangles have an important property called the \terminology{Pythagorean Theorem}.%
\begin{theorem}{Theorem}{The Pythagorean Theorem.}{}{theorem-pythagorean-theorem}%
\index{Pythagorean theorem}%
For any right triangle, the lengths of the three sides have the following relationship:%
\begin{equation*}
a^2+b^2=c^2
\end{equation*}
where \(a\) and \(b\) are the lengths of the shorter sides that meet the right angle (referred to as \terminology{legs}), and \(c\) is the length of the longest side \(c\) (which is known as the \terminology{hypotenuse}).%
\begin{figureptx}{Figure}{In a right triangle, the length of its three sides satisfy the equation \(a^2+b^2=c^2\)}{theorem-pythagorean-theorem-4}{}%
\begin{image}{0.35}{0.3}{0.35}{}%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[x=0.5cm,y=0.5cm]
  \draw (0,0) -- node[pos=0.5,below]{$a$} (4,0) --node[pos=0.5,right]{$b$} (4,3) --node[pos=0.5,above,sloped]{$c$} cycle;
  \draw (4,0.2) -- (3.8,0.2) -- (3.8,0);
\end{tikzpicture}
}%
\end{image}%
\tcblower
\end{figureptx}%
\end{theorem}
\begin{example}{Example}{}{subsection-pythagorean-theorem-4}%
Find the missing length in this right triangle.%
\begin{figureptx}{Figure}{A Right Triangle}{subsection-pythagorean-theorem-4-1-2}{}%
\begin{image}{0.265}{0.47}{0.265}{}%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[x=0.5cm,y=0.5cm]
  \draw (-8.7,0) --node[pos=0.5,below]{$x$} (0,0) --node[pos=0.5,right]{$5$} (0,5) --node[pos=0.5,sloped,above]{$10$} cycle;
  \draw (-0.4,0) -- (-0.4,0.4) -- (0,0.4);
\end{tikzpicture}
}%
\end{image}%
\tcblower
\end{figureptx}%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{subsection-pythagorean-theorem-4-2}{}\quad{}We will use the Pythagorean Theorem to solve for \(x\):%
\begin{align*}
5^2+x^2\amp=10^2\\
25+x^2\amp=100\\
x^2\amp=75\\
x\amp=\sqrt{75}\amp\text{(no need to consider }{-\sqrt{75}}\text{ in this context)}\\
x\amp=\sqrt{25\cdot3}\\
x\amp=5\sqrt{3}
\end{align*}
The missing length is \(x=5\sqrt{3}\).%
}\end{example}
\begin{example}{Example}{}{subsection-pythagorean-theorem-5}%
Keisha is designing a wooden frame in the shape of a right triangle, as shown in \hyperref[figure-wooden-frame]{Figure~15}. The legs of the triangle are \SI{3}{\foot} and \SI{4}{\foot}. How long should she make the diagonal side? Use the Pythagorean Theorem to find the length of the hypotenuse.%
\begin{sidebyside}{2}{0}{0}{0.06}%
\begin{sbspanel}{0.65}%
According to Pythagorean Theorem, we have:%
\begin{align*}
c^2\amp=a^2+b^2\\
c^2\amp=3^2+4^2\\
c^2\amp=25
\end{align*}
%
\end{sbspanel}%
\begin{sbspanel}{0.29}%
\begin{panelfigureptx}{Figure}{}{figure-wooden-frame}{}%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[x=0.5cm,y=0.5cm]
  \draw (0,0) node[below left]{$B$} -- node[pos=0.5,below]{$a=4\,\text{ft}$}
    (4,0) node[below right]{$C$} -- node[pos=0.5,right]{$b=3\,\text{ft}$}
    (4,3) node[above right]{$A$} -- node[pos=0.5,above,sloped]{$c$}
    cycle;
  \draw (4,0.2) -- (3.8,0.2) -- (3.8,0);
\end{tikzpicture}
}%
\tcblower
\end{panelfigureptx}%
\end{sbspanel}%
\end{sidebyside}%
\par
Now we have a quadratic equation that we need to solve. We need to find the number that has a square of \(25\). That is what the square root operation does.%
\begin{align*}
c\amp=\sqrt{25}\\
c\amp=5
\end{align*}
The diagonal side Keisha will cut is \SI{5}{\foot} long.%
\par
Note that \(-5\) is also a solution of \(c^2=25\) because \((-5)^2=25\). But a length cannot be a negative number. We need to include both solutions when they are relevant, but also understand when some physical context makes one of the solutions nonsensical.%
\end{example}
\begin{example}{Example}{}{subsection-pythagorean-theorem-6}%
A \(16.5\)ft ladder is leaning against a wall. The distance from the base of the ladder to the wall is \(4.5\) feet. How high on the wall does the ladder reach?%
\begin{sidebyside}{2}{0}{0}{0.06}%
\begin{sbspanel}{0.66}%
The Pythagorean Theorem says:%
\begin{align*}
a^2+b^2\amp=c^2\\
4.5^2+b^2\amp=16.5^2\\
20.25+b^2\amp=272.25\\
\intertext{Now we need to isolate \(b^2\) in order to solve for \(b\):}
20.25+b^2\subtractright{20.25}\amp=272.25\subtractright{20.25}\\
b^2\amp=252\\
\intertext{We use the square root property. Because this is a geometric situation we only need to use the principal square root:}
b\amp=\sqrt{252}\\
\intertext{Now simplify this radical and then approximate it:}
b\amp=\sqrt{36\cdot 7}\\
b\amp=6\sqrt{7}\\
b\amp\approx 15.87
\end{align*}
%
\end{sbspanel}%
\begin{sbspanel}{0.28}%
\begin{panelfigureptx}{Figure}{Leaning Ladder}{subsection-pythagorean-theorem-6-2-2}{}%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[x=0.5cm,y=0.5cm]
  \draw (-9,0) -- (-4.5,0) --node[pos=0.5,below]{$a=4.5\,\text{ft}$} (0,0) --node[pos=0.5,right]{$b$}  (0,15.9) -- (0,18);
  \draw[ultra thick] (-4.5,0) --node[sloped,pos=0.5,above]{$c=16.5\,\text{ft}$} (0,15.9);
  \draw (-0.6,0) -- (-0.6,0.6) -- (0,0.6);
\end{tikzpicture}
}%
\tcblower
\end{panelfigureptx}%
\end{sbspanel}%
\end{sidebyside}%
\par
The ladder reaches about \(15.87\) feet high on the wall.%
\end{example}

\typeout{Subsection 1.2.1 Solving Quadratic Equations with the Quadratic Formula}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{Solving Quadratic Equations with the Quadratic Formula}{}{Solving Quadratic Equations with the Quadratic Formula}{}{}{section-the-quadratic-formula-4}
The standard form for a quadratic equation is%
\begin{equation*}
ax^2+bx+c=0
\end{equation*}
where \(a\) is some nonzero number.%
\par
When \(b=0\) and the equation's form is \(ax^2+c=0\), then we can simply use the square root property to solve it as we did with equations like this in \hyperref[section-solving-quadratic-equations-by-using-a-square-root]{Section~1}. But can we solve equations where \(b\neq0\)? A general method for doing this is to use the \terminology{quadratic formula}.%
\begin{fact}{Fact}{The Quadratic Formula.}{}{fact-the-quadratic-formula}%
\index{solving!quadratic equations!quadratic formula}%
For any quadratic equation \(ax^2+bx+c=0\) with \(a\neq0\), the solutions are given by%
\begin{equation*}
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
\end{equation*}
%
\end{fact}
As we have seen from solving quadratic equations in \hyperref[section-solving-quadratic-equations-by-using-a-square-root]{Section~1}, there can be two solutions to a quadratic equation. Both solutions are represented in the quadratic formula because of the \(\pm\) symbol. We could write the two solutions separately:%
\begin{align*}
x=\frac{-b-\sqrt{b^2-4ac}}{2a}\amp\amp\text{ or }\amp\amp x=\frac{-b+\sqrt{b^2-4ac}}{2a}
\end{align*}
%
\par
This method for solving quadratic equations will work to solve \emph{every} quadratic equation. It is most helpful when \(b\ne0\).%
\begin{example}{Example}{}{example-quadratic-equation-flying-object}%
Linh is in a physics class that launches a tennis ball from a rooftop that is \(90.2\) feet above the ground. They fire it directly upward at a speed of \(14.4\) feet per second and measure the time it takes for the ball to hit the ground below. We can model the height of the tennis ball, \(h\), in feet, with the quadratic equation \(h=-16t^2+14.4t+90.2\), where \(x\) represents the time in seconds after the launch. According to the model, when should the ball hit the ground?%
\par
The ground has height \(0\) feet, so we should substitute \(0\) in for \(h\). This gives us the quadratic equation:%
\begin{equation*}
0=-16t^2+14.4t+90.2
\end{equation*}
We cannot solve this equation with the square root property, so we will use the quadratic formula. First we will identify \(\highlight{a=-16}\), \(\highlight{b=14.4}\), and \(\highlight{c=90.2}\), and substitute these into the quadratic formula:%
\begin{align*}
t\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
t\amp=\frac{-(\substitute{14.4})\pm\sqrt{(\substitute{14.4})^2-4(\substitute{-16})(\substitute{90.2})}}{2(\substitute{-16})}\\
t\amp=\frac{-14.4\pm\sqrt{5980.16}}{-32}
\end{align*}
These are the exact solutions but because we have a physical context we want to approximate the solutions with decimals.%
\begin{equation*}
t\amp\approx-1.966\qquad\text{or}\qquad t\approx2.866
\end{equation*}
We don't use the negative solution because a negative time does not make sense in this context. The ball will hit the ground approximately \(2.866\) seconds after it is launched.%
\end{example}
The quadratic formula can be used to solve any quadratic equation, but it requires that you remembering the formula correctly and that you correctly identify \(a\), \(b\), and \(c\). Also, that you don't make any arithmetic mistakes when you simplify. We recommend that you always check if you could use the square root property before using the quadratic formula.%
\begin{example}{Example}{}{section-the-quadratic-formula-4-9}%
Solve for \(x\) in \(2x^2-9x+5=0\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-4-9-2}{}\quad{}First, we check and see that we cannot use the square root property (because \(b\neq0\)) so we will use the quadratic formula. We identify \(a=2\), \(b=-9\), and \(c=5\). Substituting these into the quadratic formula:%
\begin{align*}
x\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
x\amp=\frac{-(\substitute{-9})\pm\sqrt{(\substitute{-9})^2-4(\substitute{2})(\substitute{5})}}{2(\substitute{2})}\\
x\amp=\frac{9\pm\sqrt{81-40}}{4}\\
x\amp=\frac{9\pm\sqrt{41}}{4}
\end{align*}
This is fully simplified because we cannot simplify \(\sqrt{41}\) or reduce the fraction. The solution set is \(\left\{\frac{9-\sqrt{41}}{4},\frac{9+\sqrt{41}}{4}\right\}\). In this exercise, there is no reason to approximate these with decimals.%
}\end{example}
When a quadratic equation does not start out in standard form we must convert it to standard form before we can clearly identify the values of \(a\), \(b\), and \(c\).%
\begin{example}{Example}{}{example-solve-quadratic-equation-using-quadratic-formula}%
Solve for \(x\) in \(x^2=-10x-3\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{example-solve-quadratic-equation-using-quadratic-formula-2}{}\quad{}First, we convert the equation into standard form by adding \(10x\) and \(3\) to each side of the equation:%
\begin{equation*}
x^2+10x+3=0
\end{equation*}
Next, we check that we cannot use the square root property so we will use the quadratic formula. We identify \(a=1\), \(b=10\) and \(c=3\). Substituting them into the quadratic formula:%
\begin{align*}
x\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
x\amp=\frac{-\substitute{10}\pm\sqrt{(\substitute{10})^2-4(\substitute{1})(\substitute{3})}}{2(\substitute{1})}\\
x\amp=\frac{-10\pm\sqrt{100-12}}{2}\\
x\amp=\frac{-10\pm\sqrt{88}}{2}
\end{align*}
We notice that the radical can be simplified:%
\begin{align*}
x\amp=\frac{-10\pm2\sqrt{22}}{2}\\
x\amp=\frac{-10}{2}\pm\frac{2\sqrt{22}}{2}\\
x\amp=-5\pm\sqrt{22}
\end{align*}
The solution set is \(\{-5-\sqrt{22}, -5+\sqrt{22}\}\).%
}\end{example}
\begin{remark}{Remark}{}{section-the-quadratic-formula-4-12}%
The irrational solutions to quadratic equations can be checked, but doing this sometimes takes a lot of simplification and is not shown throughout this section. As an example of how much effort goes into a direct check, we will check the solution of \(-5+\sqrt{22}\) from \hyperref[example-solve-quadratic-equation-using-quadratic-formula]{Example~5}. We need to replace \(x\) with \(-5+\sqrt{22}\) and check that the two sides of the equation are equal. This check is shown here:%
\begin{align*}
x^2\amp=-10x-3\\
(\substitute{-5+\sqrt{22}})^2\amp\wonder{=}-10(\substitute{-5+\sqrt{22}})-3\\
(-5)^2+2(-5)(\sqrt{22})+(\sqrt{22})^2\amp\wonder{=}-10(-5+\sqrt{22})-3\\
25-10\sqrt{22}+22 \amp\wonder{=}50-10\sqrt{22}-3\\
47-10\sqrt{22}\amp\confirm{=}47-10\sqrt{22}
\end{align*}
It worked, and it took a lot of effort. As an alternative, we could use a calculator to find \(-5+\sqrt{22}\approx-0.3096\) and see if this decimal approximation appears to be close to working.%
\begin{align*}
x^2\amp=-10x-3\\
(\substitute{-0.3096})^2\amp\wonder{=}-10(\substitute{-0.3096})-3\\
0.09585216\amp\wonder{=}0.096
\end{align*}
These are close. So with the help of a calculator, checking like this can give reasonable confidence that the solution we found is valid.%
\end{remark}
The radicand from the quadratic formula, \(b^2-4ac\), is called the \terminology{discriminant}. When it is a negative number, the quadratic equation has no real             \index{discriminant} solution.%
\begin{example}{Example}{}{example-quadratic-equation-no-solution}%
Solve for \(y\) in \(y^2-4y+8=0\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{example-quadratic-equation-no-solution-2}{}\quad{}Identify \(a=1\), \(b=-4\) and \(c=8\). Substitute them into the quadratic formula:%
\begin{align*}
y\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
\amp=\frac{-(\substitute{-4})\pm\sqrt{(\substitute{-4})^2-4(\substitute{1})(\substitute{8})}}{2(\substitute{1})}\\
\amp=\frac{4\pm\sqrt{16-32}}{2}\\
\amp=\frac{4\pm\sqrt{-16}}{2}
\end{align*}
The discriminant worked out to be \(-16\), which is negative. The square root of a negative number is not a real number, so we will conclude that this equation has no real solutions.%
}\end{example}

\begin{subsectionptx}{Subsection}{Applications}{}{Applications}{}{}{section-the-quadratic-formula-5}
Certain ``word problems'' lead to a quadratic equation where the quadratic formula may be useful.%
\begin{example}{Example}{}{section-the-quadratic-formula-5-3}%
A rectangle is \(5\) inches longer than it is wide. The total area of the rectangle is 60 square inches. How wide is the rectangle? (This is asking for the shorter dimension.)%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-5-3-2}{}\quad{}The area of a rectangle is given by multipying its two dimensions. If we let \(w\) stand for the width of the rectangle (the shorter dimension), then \(w+5\) is the length, and the total area is \(w(w+5)\). A diagram can help make more clear what needs to be done.%
}

\noindent\hskip-30pt\begin{minipage}{400pt}
\parmarginbox{%
\begin{image}{0}{1}{0}{}%
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}
  \draw (0,0) -| node[pos=0.25, below] {\(w+5\)} node[pos=0.75, right] {\(w\)} (5,3) -| cycle;
  \node at (2.5,1.5) {\(60\)};
\end{tikzpicture}
}%
\end{image}%
}{0pt}

\end{minipage}

So we must solve the equation \(w(w+5)=60\). After multiplying and moving to standard form, we have \(w^2+5w-60=0\). Using the quadratic formula:%
\begin{align*}
w\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
\amp=\frac{-5\pm\sqrt{5^2-4(1)(-60)}}{2(1)}\\
\amp=\frac{-5\pm\sqrt{265}}{2}\\
w\amp\approx-10.64\quad\text{or}\quad w\approx5.64
\end{align*}
Only the solution \(w\approx5.64\) makes sense as the width of a rectangle. So the rectangle is about \(5.64\) inches wide.%
\end{example}
\begin{inlineexercise}{Checkpoint}{}{section-the-quadratic-formula-5-4}%
Two numbers have sum \(35\text{,}\) and their product is \(-30\text{.}\) Find these two numbers.%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-5-4-3}{}\quad{}Let \(x\) be one of these numbers. Since the two numbers have sum \(35\text{,}\) it means that the other number must be \(35-x\text{.}\) Since the two numbers have product \(-30\text{,}\) we have the equation%
}\par
%
\begin{equation*}
\begin{aligned}
x(35-x)\amp=-30\\
35x-x^2\amp=-30
\end{aligned}
\end{equation*}
%
\par
This is a quadratic equation which can be rewritten into standard form by adding \(30\) to each side:%
\par
%
\begin{equation*}
\begin{gathered}
-x^2+35x+30=0
\end{gathered}
\end{equation*}
%
\par
Then, to solve for \(x\text{,}\) we apply the quadratic formula:%
\par
%
\begin{equation*}
\begin{aligned}
x\amp=\frac{-35\pm\sqrt{35^2-4(-1)(30)}}{2(-1)}\\
\amp=\frac{-35\pm\sqrt{1225+120}}{-2}\\
\amp=\frac{-35\pm\sqrt{1345}}{-2}\\
\amp=\frac{35\pm\sqrt{1345}}{2}
\end{aligned}
\end{equation*}
%
\par
So the two possible solutions for \(x\) are:%
\par
%
\begin{equation*}
\begin{gathered}
x=\frac{35-\sqrt{1345}}{2}\quad\text{or}\quad x=\frac{35+\sqrt{1345}}{2}
\end{gathered}
\end{equation*}
%
\par
Actually these are the two numbers we were looking for. They sum to \(35\) and multiply to \(-30\text{.}\)%
\end{inlineexercise}%
\begin{example}{Example}{}{section-the-quadratic-formula-5-5}%
Amita has a food stand where she sells momo (Nepali dumplings). If she charges \(p\) dollars for each momo, she estimates that she'd sell \(80{,}000-20{,}000p\) over the course of a year. (This reflects how raising the price can lead to fewer people making purchases.) What is the largest price that Amita could set to end up with a revenue of \(\$70{,}000\) for the year? (Note that revenue is not the same as profit, and we will not be accounting for Amita's expenses.)%
\par
%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-5-5-2}{}\quad{}If Amita sets the price at \(p\) dollars per momo, her total revenue will be \((\text{number sold})\cdot\text{price}\), which is \((80000-20000p)p\), which simplifies to \(80000p-20000p^2\). We have been asked to set that equal to \(70000\).%
\begin{align*}
80000p-20000p^2 \amp = 70000\\
-20000p^2+80000p-70000 \amp = 0\\
\intertext{So many zeros! We have the option to divide by \(10000\).}
-2p^2+8p-7 \amp = 0
\end{align*}
%
\begin{align*}
p\amp=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\\
\amp=\frac{-8\pm\sqrt{8^2-4(-2)(-7)}}{2(-2)}\\
\amp=\frac{-8\pm\sqrt{8}}{-4}\\
p\approx\amp 2.71 \quad\text{or}\quad x\approx1.29
\end{align*}
The possible solutions are about \(2.71\) and \(1.29\). They are both valid solutions. Amita can reach the target revenue of \(\$70{,}000\) by setting the price per momo to either \(\$1.29\) or \(\$2.71\).%
}\end{example}
\end{subsectionptx}

\begin{subsectionptx}{Subsection}{Radical Equations}{}{Radical Equations}{}{}{section-the-quadratic-formula-6}
Sometimes a radical equation gives rise to a quadratic equation, and the quadratic formula can then be useful.%
\begin{example}{Example}{}{section-the-quadratic-formula-6-3}%
Solve for \(z\) in \(\sqrt{z}+2=z\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-6-3-2}{}\quad{}We will isolate the radical first, and then square both sides.%
\begin{align*}
\sqrt{z}+2\amp=z\\
\sqrt{z}\amp=z-2\\
\left(\sqrt{z}\right)^{\highlight{2}}\amp=(z-2)^{\highlight{2}}\\
z\amp=z^2-4z+4\\
0\amp=z^2-5z+4\\
z\amp=\frac{5\pm\sqrt{(-5)^2-4(1)(4)}}{2}\\
\amp=\frac{5\pm\sqrt{25-16}}{2}\\
\amp=\frac{5\pm\sqrt{9}}{2}\\
\amp=\frac{5\pm3}{2}
\end{align*}
%
\begin{align*}
z\amp=\frac{5-3}{2}\amp\text{ or }\amp\amp z\amp=\frac{5+3}{2}\\
z\amp=1\amp\text{ or }\amp\amp z\amp=4
\end{align*}
There was a step in this process where we squared both sides of an equation. Squaring both sides of an equation can cause false equations to become true. For example \(-2=2\) is false, but if you square both sides then \(4=4\) is true. This means that when an equation solving process involves squaring both sides, and we end up with ``solutions'' like the two \(z\)-values above, they are only \emph{potential} solutions. Logically we've whittled down the list of possible solutions to just these two numbers. But we need to actually check whether or not they actually work.%
\begin{align*}
\sqrt{\substitute{1}}+2\amp\wonder{=}1\amp\sqrt{\substitute{4}}+2\amp\wonder{=}4\\
1+2\amp\reject{=}1\amp2+2\amp\confirm{=}4
\end{align*}
It turned out that \(1\) is an \terminology{extraneous solution}, but \(4\) is a valid solution. So the equation has one solution, \(4\), and the solution set is \(\{4\}\).%
}\end{example}
\begin{example}{Example}{}{section-the-quadratic-formula-6-4}%
Solve the equation \(\sqrt{2n-6}=1+\sqrt{n-2}\) for \(n\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-the-quadratic-formula-6-4-2}{}\quad{}We cannot isolate two radicals at the same time. One of the radicals is already isolated, so we will simply square both sides and then try to clean up what remains.%
\begin{align*}
\sqrt{2n-6}\amp=1+\sqrt{n-2}\\
\left(\sqrt{2n-6}\right)^{\highlight{2}}\amp=\left(1+\sqrt{n-2}\right)^{\highlight{2}}\\
2n-6\amp=1^2+2\sqrt{n-2}+\left(\sqrt{n-2}\right)^2\\
2n-6\amp=1+2\sqrt{n-2}+n-2\\
2n-6\amp=2\sqrt{n-2}+n-1\\
n-5\amp=2\sqrt{n-2}\\
\intertext{Note here that we can leave the factor of \(2\) next to the radical. We will square the \(2\) also.}
(n-5)^{\highlight{2}}\amp=\left(2\sqrt{n-2}\right)^{\highlight{2}}\\
n^2-10n+25\amp=4(n-2)\\
n^2-10n+25\amp=4n-8\\
n^2-14n+33\amp=0
\end{align*}
%
\begin{align*}
n\amp=\frac{14\pm\sqrt{14^2-4(1)(33)}}{2}\\
\amp=\frac{14\pm\sqrt{196-132}}{2}\\
\amp=\frac{14\pm\sqrt{64}}{2}\\
\amp=\frac{14\pm8}{2}
\end{align*}
%
\begin{align*}
n\amp=\frac{14-8}{2}\amp\text{ or }\amp\amp n\amp=\frac{14+8}{2}\\
n\amp=3\amp\text{ or }\amp\amp n\amp=11
\end{align*}
So our two potential solutions are \(3\) and \(11\). We should now verify that they truly are solutions.%
\begin{align*}
\sqrt{2(\substitute{3})-6}\amp\wonder{=}1+\sqrt{\substitute{3}-2}\amp\sqrt{2(\substitute{11})-6}\amp\wonder{=}1+\sqrt{\substitute{11}-2}\\
\sqrt{6-6}\amp\wonder{=}1+\sqrt{1}\amp\sqrt{22-6}\amp\wonder{=}1+\sqrt{9}\\
\sqrt{0}\amp\wonder{=}1+1\amp\sqrt{16}\amp\wonder{=}1+3\\
0\amp\reject{=}2\amp4\amp\confirm{=}4
\end{align*}
So, \(11\) is the only solution. The solution set is \(\{11\}\).%
}\end{example}

\typeout{Subsection 1.3.1 Imaginary Numbers}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{Imaginary Numbers}{}{Imaginary Numbers}{}{}{section-complex-solutions-to-quadratic-equations-4}
Let's take a fresh look at a square root with a negative radicand. Remember that the reason \(\sqrt{16}=4\) is because \(4\cdot4=16\). So what might \(\sqrt{-16}\) mean? There is no real number that we can square to get \(-16\), because when you square a real number, the result simply cannot be negative. You might think about \(4\) and \(-4\), but:%
\begin{equation*}
4\cdot4=16\text{ and }(-4)(-4)=16
\end{equation*}
so neither of those could be \(\sqrt{-16}\). Mathematicians realized it was possible to keep track of square roots of negative numbers \emph{symbolically} even though the symbols do not represent real numbers.%
\begin{definition}{Definition}{Imaginary Numbers.}{definition-imaginary-number}%
\index{imaginary unit}%
\index{imaginary numbers}%
The \terminology{imaginary unit}, \(i\), is defined by \(i=\sqrt{-1}\). The \href{https://en.wikipedia.org/wiki/Imaginary_number}{imaginary unit}\footnotemark{} satisfies the equation \(i^2=-1\). A real number times \(i\), such as \(4i\), is called an \terminology{imaginary number}.%
\end{definition}
\footnotetext[1]{\nolinkurl{en.wikipedia.org/wiki/Imaginary_number}\label{definition-imaginary-number-4-1-5}}%
Now we can simplify square roots with negative radicands like \(\sqrt{-16}\).%
\begin{align*}
\sqrt{-16}\amp=\sqrt{-1\cdot16}\\
\amp=\sqrt{-1}\cdot\sqrt{16}\\
\amp=i\cdot4\\
\amp=4i
\end{align*}
%
\par
Imaginary numbers are used in electrical engineering, physics, computer science, and advanced mathematics. Let's look at some more examples.%
\begin{example}{Example}{}{section-complex-solutions-to-quadratic-equations-4-6}%
Simplify \(\sqrt{-2}\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-complex-solutions-to-quadratic-equations-4-6-2}{}\quad{}%
\begin{align*}
\sqrt{-2}\amp=\sqrt{-1\cdot2}\\
\amp=\sqrt{-1}\cdot\sqrt{2}\\
\amp=i\sqrt{2}
\end{align*}
We write the \(i\) in front of the radical because it can be easy to mix up \(\sqrt{2}i\) with \(\sqrt{2i}\) if you don't draw the radical very carefully. It's more clear as \(i\sqrt{2}\).%
}\end{example}
\begin{example}{Example}{}{section-complex-solutions-to-quadratic-equations-4-7}%
Simplify \(\sqrt{-72}\).%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-complex-solutions-to-quadratic-equations-4-7-2}{}\quad{}Not only can we separate the \(\sqrt{-1}\) factor, but also in this example there is a square factor of \(72\) that can be used to simplify the expression more.%
\begin{align*}
\sqrt{-72}\amp=\sqrt{-1\cdot36\cdot2}\\
\amp=\sqrt{-1}\cdot\sqrt{36}\cdot\sqrt{2}\\
\amp=6i\sqrt{2}
\end{align*}
%
}\end{example}
\end{subsectionptx}

\typeout{Subsection 1.3.2 Solving Quadratic Equations with Imaginary Solutions}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{Solving Quadratic Equations with Imaginary Solutions}{}{Solving Quadratic Equations with Imaginary Solutions}{}{}{section-complex-solutions-to-quadratic-equations-5}
Back in \hyperref[example-no-real-solution]{Example~{\xreffont\ref{example-no-real-solution}}}, we examined an equation that had no real solution. Let's revisit that example now that we are aware of imaginary numbers.%
\begin{example}{Example}{}{section-complex-solutions-to-quadratic-equations-5-3}%
Solve for \(x\) in \(x^2+49=0\), where \(x\) might not be a real number.%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-complex-solutions-to-quadratic-equations-5-3-2}{}\quad{}There is no ``\(x\)'' term, so we will use the square root method to solve this equation.%
\begin{align*}
x^2+49\amp=0\\
x^2\amp=-49\\
x\amp=\pm\sqrt{-49}\\
x\amp=\pm\sqrt{49\cdot-1}\\
x\amp=\pm\sqrt{49}\cdot\sqrt{-1}\\
x\amp=\pm 7i
\end{align*}
%
\begin{align*}
x\amp=-7i\amp\text{ or }\amp\amp x\amp=7i
\end{align*}
The solution set is \(\{-7i,7i\}\).%
}\end{example}
\begin{example}{Example}{}{section-complex-solutions-to-quadratic-equations-5-4}%
Solve for \(p\) in \(p^2+75=0\), where \(p\) might not be a real number.%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-complex-solutions-to-quadratic-equations-5-4-2}{}\quad{}There is no ``\(p\)'' term so we will use the square root method.%
\begin{align*}
p^2+75\amp=0\\
p^2\amp=-75\\
p\amp=\pm\sqrt{-75}\\
p\amp=\pm\sqrt{25\cdot-1\cdot3}\\
p\amp=\pm\sqrt{25}\cdot\sqrt{-1}\cdot\sqrt{3}\\
p\amp=\pm 5i\sqrt{3}
\end{align*}
%
\begin{align*}
p\amp=-5i\sqrt{3}\amp\text{ or }\amp\amp p\amp=5i\sqrt{3}
\end{align*}
The solution set is \(\left\{-5i\sqrt{3},5i\sqrt{3}\right\}\).%
}\end{example}
\end{subsectionptx}

\typeout{Subsection 1.3.3 Solving Quadratic Equations with Complex Solutions}
\typeout{************************************************}
%
\begin{subsectionptx}{Subsection}{Solving Quadratic Equations with Complex Solutions}{}{Solving Quadratic Equations with Complex Solutions}{}{}{section-complex-solutions-to-quadratic-equations-6}
Sometimes we need to work with a sum of a real number and an imaginary number, like \(3+2i\) or \(-4-8i\). These combinations are called ``complex numbers''.%
\begin{definition}{Definition}{Complex Number.}{definition-complex-number}%
\index{complex number}%
A \terminology{complex number} is a number that can be expressed in the form \(a + bi\), where \(a\) and \(b\) are real numbers and \(i\) is the imaginary unit. In this expression, \(a\) is the \terminology{real part} and \(b\) (not \(bi\)) is the \terminology{imaginary part} of the \href{https://en.wikipedia.org/wiki/Complex_number}{complex number}\footnotemark{}.%
\end{definition}
\footnotetext[2]{\nolinkurl{en.wikipedia.org/wiki/Complex_number}\label{definition-complex-number-3-1-12}}%
Note that technically, real numbers (like \(5\)) are complex numbers too (like \(5+0i\)). And similarly, imaginary numbers (like \(7i\)) are complex numbers too (like \(0+7i\)).%
\begin{example}{Example}{}{section-complex-solutions-to-quadratic-equations-6-5}%
Solve for \(m\) in \((m-1)^2+18=0\), where \(m\) might not be a real number.%
\par\smallskip%
{\makeatletter\@beginparpenalty=10000\makeatother\noindent\textbf{\blocktitlefont Explanation}.\hypertarget{section-complex-solutions-to-quadratic-equations-6-5-2}{}\quad{}This equation has a squared expression so we will use the square root method.%
\begin{align*}
(m-1)^2+18\amp=0\\
(m-1)^2\amp=-18\\
m-1\amp=\pm\sqrt{-18}\\
m-1\amp=\pm\sqrt{-1\cdot9\cdot2}\\
m-1\amp=\pm\sqrt{-1}\cdot\sqrt{9}\cdot\sqrt{2}\\
m-1\amp=\pm i\cdot3\sqrt{2}\\
m\amp=1\pm i\cdot3\sqrt{2}
\end{align*}
%
\begin{align*}
m\amp=1-3i\sqrt{2}\amp\text{ or }\amp\amp m\amp=1+3i\sqrt{2}
\end{align*}
The solution set is \(\left\{1-3i\sqrt{2}, 1+3i\sqrt{2}\right\}\).%
}\end{example}
\begin{example}{Example}{}{example-solve-quadratic-complex-solution}%
In an advanced math course, you might study the relationship between a lynx polulation (or any generic predator) and a hare population (or any generic prey) as time passes. For example, if the predator population is high, they will eat many prey. But then the prey population will become low, so the predators will go hungry and have fewer offspring. With time, the predator population will decline, and that will lead to a rebound in the prey population. Then prey will be plentiful, and the preadator population will rebound, and the whole situaiton starts over. This cycle may take years or even decades to play out.%
\par
Strange as it may seem, to understand this phenomenon mathematically, you will need to solve equations similar to:%
\begin{equation*}
(1-t)(3-t)+10=0
\end{equation*}
Let's practice solving this equation now.%
\begin{align*}
(1-t)(3-t)+10\amp=0\\
3-t-3t+t^2+10\amp=0\\
t^2-4t+13\amp=0
\end{align*}
We can try the quadratic formula.%
\begin{align*}
t\amp=\frac{4\pm\sqrt{(-4)^2-4(1)(13)}}{2(1)}\\
\amp=\frac{4\pm\sqrt{16-52}}{2}\\
\amp=\frac{4\pm\sqrt{-36}}{2}\\
\amp=\frac{4\pm\sqrt{-1}\cdot\sqrt{36}}{2}\\
\amp=\frac{4\pm i\cdot6}{2}\\
\amp=2\pm3i
\end{align*}
These two solutions, \(2-3i\) and \(2+3i\) have implications for how fast the predator and prey populations rise and fall over time, but you will study that in a later math course.%
\end{example}
Note that in \hyperref[example-solve-quadratic-complex-solution]{Example~9}, the expressions \(2+3i\) and \(2-3i\) are fully simplified. In the same way that the terms \(2\) and \(3x\) cannot be combined, the terms \(2\) and \(3i\) can not be combined.%
\begin{remark}{Remark}{}{section-complex-solutions-to-quadratic-equations-6-8}%
Each complex solution to a quadratic equation can be checked, just as every real solution can be checked. To check the solution \(2+3i\) from \hyperref[example-solve-quadratic-complex-solution]{Example~9}, we can replace \(t\) with \(2+3i\) and check that the two sides of the equation are equal. In doing so, we will need to use the fact that \(i^2=-1\). This check is shown here:%
\begin{align*}
(1-t)(3-t)+10\amp=0\\
(1-\substitute{(2+3i)})(3-\substitute{(2+3i)})+10\amp\wonder{=}0\\
(1-2-3i)(3-2-3i)+10\amp\wonder{=}0\\
(-1-3i)(1-3i)+10\amp\wonder{=}0\\
-1+3i-3i+(3i)^2+10\amp\wonder{=}0\\
9+9i^2\amp\wonder{=}0\\
9-9\amp\confirm{=}0
\end{align*}
%
\end{remark}
